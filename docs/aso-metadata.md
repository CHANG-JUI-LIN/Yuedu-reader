# App Store 文案（3.0.0，依地區重寫）

限制：名稱 30、副標題 30、關鍵字 100（逗號分隔、不加空格）、宣傳文字 170、描述 4000。
關鍵字欄位只放名稱／副標題**沒有出現過**的詞（Apple 會自動組合，重複是浪費）；不放其他公司的商標名（古騰堡、青空文庫等只寫在描述裡）。
描述不參與搜尋排名，只影響轉換，前 3 行最重要。

3.0 的主軸：書不再分散在各個來源裡，以「作品」為中心——統一各種來源、建立自己的書庫、自由探索，探索首頁可以自己編排。
文案只寫程式真的做到的：探索是把各來源的欄目排在同一頁（不是依作品合併）；**搜尋**才依作品合併；WebDAV 不在搜尋裡；iCloud 不同步首頁配置、模組、聚合設定。
中國大陸區已下架（2026-10-24），簡體中文版本面向新加坡、馬來西亞等地區。

截圖：每個語言 7 張，順序 探索 → 資源庫 → 編輯首頁 → 搜尋 → 作品詳情 → 書架 → 閱讀器；畫面裡只有公有領域的書（Standard Ebooks、古騰堡、維基文庫、青空文庫），封面畫作的作者都已過世超過 70 年。標語見各語言最後一節。
