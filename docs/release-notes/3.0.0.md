# 閱讀 3.0.0 更新日誌（自 2.0.7 起）

範圍：2.0.7 最後一個 build（build 9，`0c3f6c76`，2026-10-08）之後到 main 上的所有提交（到 `c0dc55f0`，2026-10-28，build 7 之後），共 776 個。2.0.8 沒有發佈過，它的內容併進這一版。

---

## App Store「新功能」（可直接貼上）

閱讀 3.0 是一次大改版：書不再分散在各個來源裡，而是以「作品」為中心，集中在同一個地方探索、搜尋和管理。

【全新分頁】
・分頁改成：探索、書架、資源庫、設定、搜尋，打開 App 先到探索
・新增「資源庫」分頁：模組、來源配置、遠端書庫（WebDAV／OPDS／Calibre）、訂閱都列在這裡；新增來源統一在「設定 → 資源」

【探索】
・探索首頁可以自己編排：新增、刪除、調整欄目順序；參考 Apple Books 的多種呈現方式，包括頂部輪播圖、排行榜、分類卡片、拼貼卡片，每種都有即時預覽
・新增「AI 推薦」，附推薦理由
・新增「趨勢」：依維基百科瀏覽量排出的熱門小說、完結作品和經典名著，每天更新
・新增「繼續閱讀」卡片、精選、專題集合、系列下一本、書架
・首頁配置有自己的按鈕和管理頁，每組首頁可以設照片

【作品詳情】
・每本書都有一頁「作品詳情」：簡介、目錄、同系列、同題材作品、作品資訊
・開啟時自動找出你已啟用的來源裡有哪些能讀這本書
・同系列的其他封面在主視覺後方展開

【搜尋】
・一次搜尋書架、來源配置、遠端書庫、公有書庫和 Open Library，結果合併成作品清單
・依類型分組篩選，結果會自動載入到底

【模組】
・新的模組系統：古騰堡、青空文庫、Open Library、小説家になろう、Bangumi、AniList、openBD、趨勢都是官方模組
・可以匯入第三方模組，也能從模組加書上書架、直接閱讀
・自動補齊書籍資料：缺封面、簡介、分類時，從模組和 Open Library 自動補上

【閱讀】
・全新閱讀介面：底部兩個浮動膠囊，進度、目錄、深色、聽書、主題一手可及
・全書搜尋：搜尋整本書的每一章，支援正則表達式
・新的語音朗讀面板；關掉書後朗讀繼續，從書架的膠囊回到朗讀處
・EPUB 可以調整行距與段距，也能選擇是否套用書本自己的間距
・匯入的書也能換源：檔案、來源配置、遠端書庫、模組都是同一部作品的版本
・頁面底部對齊，文字填滿整頁
・線上章節裡的影片和網頁可以直接在章節內播放
・修正 ruby 注音重畫時位置跑掉、直排捲動跳位、iPad 邊距等排版問題
・匯入 Reeden 主題包與高亮包，可以編輯九宮格框
・段評、本章說、作者說、神評論卡片有內建「玻璃」樣式，也可以自訂範本

【其他】
・支援 iPhone 橫向與 iPhone Duo：整個 App 跟著自己的視窗排版，仿真翻頁雙頁從中間書脊翻
・第一次打開時有新手導覽，最後一步直接帶你去找書、加來源或匯入檔案；可以在「設定 → 關於」重看
・新的「回饋中心」：可以雙向回覆、收到回覆時通知，附截圖回報問題
・替換規則可以多選一次刪除
・AI 摘要、翻譯、人物分析速度大幅提升
・Widget 與即時動態支援五種語言
・大量效能與穩定性改進

## 完整更新內容

### 分頁與架構
- 分頁改為 探索・書架・資源庫・設定・搜尋，打開 App 先到探索。RSS 不再是獨立分頁，訂閱移到資源庫。
- 新增「資源庫」分頁，參考圖式卡片，有格狀和列表兩種顯示。來源依分組排列，可以搜尋。
  - 列出模組、來源配置、遠端書庫、訂閱。官方模組和匯入的模組合成一個「模組」區，放在最上面。
  - 來源配置只列有發現頁的來源，遠端書庫連線後才出現，不再有空的引導卡片。
  - 右上「•••」在每個 iOS 版本都是原生選單。
- 新增來源一律在「設定 → 資源」：來源配置管理、模組、遠端書庫各自從工具列新增，資源庫只負責列出。設定重新分組為一般、資源、閱讀、資料、支援。
- 移除「Legado 資料遷移」：來源配置照一般匯入流程匯入即可，舊的書架遷移會遺失封面、簡介和進度。
- 「遠端書庫」整合到設定裡集中管理：WebDAV、OPDS、Calibre 連線。
- OPDS 認得舊式的封面標記（Talebook、calibre 2.x），這類書庫的書終於有封面。
- 來源配置管理在所有 iOS 版本都改成推入頁面，不再用 sheet，修正 iOS 17 上匯入按鈕失效的問題。
- 中文介面統一稱「來源配置」，其他語言稱 Source。

### 新手導覽
- 每台裝置第一次打開時，先看一段導覽再進分頁：歡迎、從探索找書、一部作品，一個頁面、連接你的所有資源、長時間閱讀也舒服、選一個起點。
- 每頁標出功能在哪個分頁；從分頁列隱藏的分頁，不會出現在導覽裡。
- 最後一頁可以直接開始：去探索找書、新增來源配置、連接書庫、匯入檔案；也可以按「略過」。
- 「設定 → 關於 → 新手導覽」可以再看一次。
- 冷啟動時直接打開的書會蓋在導覽上面，不會被導覽擋住。
- iPhone 橫向和 iPhone Duo 上，導覽頁不再從側邊露出相鄰的頁面。

### 探索
- 探索的根頁就是首頁，可以直接在首頁底部進入「編輯首頁」，新增、刪除、排序欄目。
- 呈現方式：大型閱讀卡片、精簡閱讀卡片、橫向單排書架、多行橫向輪播、固定封面網格、圖文資訊清單、精選（一頁一本並附分類）、專題集合（書單）。選擇時有即時預覽，每種版面配合適的範例封面。
- 參考 Apple Books 再加入：色帶書架、大型封面書架、一大四小、排行榜（每個排行一欄、列出前三名）、分類卡片、拼貼卡片、大圖卡片（可以換成自己的照片）。
- 首頁第一個色帶欄目就是「頂部輪播圖」，從螢幕邊緣畫到頂端，第一本封面的顏色延伸到導覽列下方。編輯首頁的最上方可以換首頁配置的照片、改名、選擇輪播數據、關閉或開啟輪播圖。
- 書單類版面（專題集合、分類卡片、拼貼卡片、大圖卡片）可以用任何來源：模組的清單、來源配置的分類、書庫、古騰堡和青空文庫的清單、書架的分組。
- 編輯首頁裡每個欄目都畫成一列，放在灰色框裡；列可以左右滑動，點一下開設定，長按拖曳排序。
- 沒有改動過的「預設」首頁會一次換成新的呈現方式（只換版面，不增刪欄目）。
- 修改「中繼資料語言偏好推薦」後，「預設」裡的官方模組欄目跟著換成新語言的排行。
- 「首頁配置」取代舊的自訂頁面，可以有多組首頁，從探索右上角的首頁配置按鈕切換，每組可以設自己的照片。
- 公有書庫有自己的首頁欄目，例如新上架作品。
- 新欄目：繼續閱讀（Apple Books 式卡片）、系列下一本、精選書單、訂閱的最新文章、古騰堡熱門。
- 「AI 推薦」官方模組：首頁欄目和獨立頁面，作品詳情顯示推薦理由；找不到可讀來源時會標示「未找到可用來源」。
- 「趨勢」官方模組：依維基百科瀏覽量排出今日熱門、本月熱門、今年熱門、完結推薦和經典名著，每天在伺服器更新，不直接抓網文平台。
  - 地區有華語（繁）、華語（簡）、日本、英語，預設跟隨「中繼資料語言偏好推薦」，改語言後欄目立刻換成那個地區。
  - 同一系列只列第一集，系列名顯示在作者下面；大部分作品附封面。
- 新安裝的預設首頁依語言放上官方模組的排行榜：中文是 Bangumi 的小說與漫畫排行，日文是小説家になろう週排行，英文是 AniList 熱門小說與漫畫。已經存過的首頁不會被改。
- 新欄目「書架」：書架上的書依書架的排序列出，點了直接開始閱讀；「繼續閱讀」裡書架上的書也直接打開閱讀器。
- 進出「編輯首頁」時，每個欄目在原地變形成卡片再變回來（開啟「減少動態效果」時直接切換）。
- 下拉重新整理會一併抓取訂閱內容，「查看全部」直接開啟訂閱。
- 聚合設定改成 Emby 式首頁設定：首頁欄目、「顯示在最新」、「隱藏已讀」。
- 「偏好閱讀語言」和「推薦範圍」合併成一個選單「中繼資料語言偏好推薦」，預設跟隨 App 語言；那個語言的書排前面，其他語言的書不再被排除。
- 首頁和作品詳情的書名、作者、簡介跟著「中繼資料語言偏好推薦」：選繁體或簡體時轉成那種字；只有日文簡介的書顯示「沒有繁體中文簡介」（或簡體），中日對照的簡介只留中文。
- 資源庫裡的古騰堡和青空文庫改成跟其他官方模組一樣的頁面，說明它提供什麼；書單照樣可以放在首頁欄目。
- 刪除舊的探索設定和範圍切換，工具列只留一個「•••」。
- 切換首頁配置時從首頁最上面開始，修正捲到下面再切換時整頁空白、只剩「編輯首頁」。
- 「從設定範本新增」：「預設配置」用 App 內建的預設欄目建立，不再複製你改過的「預設」；「空白模板」建立沒有欄目的首頁。不再內建「空白」首頁。首頁配置頁的「編輯」可以調整「預設」的位置。
- 「預設」首頁配置也可以刪除，只剩一組時不能刪；要找回來就用「從設定範本新增」的「預設配置」。
- 修正 iOS 26.4 上「新增欄目」點「資料來源」後跳回版面選擇、選擇內容來源跟著關掉，無法新增欄目。
- 修正從探索和資源庫打開的瀏覽器裡，點「書籤」才打開就被關掉（探索在 iOS 26.4，資源庫在較新的版本也會）。
- 每次打開書都會把它排回「繼續閱讀」第一個，書架的「最近閱讀」排序也一樣。以前只有第一次打開才更新，從作品詳情或探索卡片再讀一次的書會停在原位，甚至被擠出欄目。
- 修正首頁很短、最後幾個欄目隱藏時，進入編輯首頁會卡死。

### 作品詳情
- 從書架、探索、搜尋、資源庫打開任何一本書，都進同一頁「作品詳情」。
- 版面依序是：封面主視覺、簡介、作品關聯、作品資訊。主要操作只有一個，「繼續閱讀」的進度直接寫在按鈕上。
- 打開就讀取目錄，目錄章節會跳到正確的錨點。
- 同系列：主視覺標出系列名，下方接著列出各卷。
- 同系列其他卷的封面在主視覺封面後方展開，左右最多各兩本；趨勢裡的華語和日本作品用 Bangumi 的單行本封面。封面載入完才展開。
- 同題材作品：標題旁可以選要看哪個分類。
- 打開時會在已啟用的來源中找這本作品，列出能讀的來源與版本。
- 只有資料、還沒有可讀來源的作品（AI 推薦、趨勢、Bangumi），找到第一個能讀的來源就直接用它；還在找的時候目錄顯示載入中。
- 書架上那本的書名、作者、封面、簡介優先顯示；手動修改的簡介會保留。
- 「開始閱讀」和「加入書架」永遠左右並排。
- 在書架上那本書的作品詳情裡換源，會直接換掉書架那本的來源，不再重複詢問「加入書架」。
- 在目錄選的章節，漫畫和有聲書也會從那一章開始。
- 沒有可閱讀的來源時，改在目錄區塊說明，不再佔掉一大塊畫面。
- HTML 格式的簡介收合時停在完整的一行，不再切到半行字。

### 搜尋
- 一次搜尋所有地方，結果依作品合併成一張清單：
  - 書架（邊打字邊找）
  - 來源配置
  - OPDS／Calibre 遠端書庫
  - 古騰堡、青空文庫
  - Open Library
  - 模組
- 依類型分組，有「類型」篩選。
- 不再分頁：自動抓完所有結果，會依手機溫度和低耗電模式調整速度。
- 能分辨「來源搜尋失敗」和「沒有結果」，失敗會記錄下來方便診斷。
- 換源、換封面改用作品比對規則，配對更準。
- 「數據來源」列出每個來源的結果數，可以分用途勾選。
- 從作品詳情的作者、標籤打開的搜尋改成全螢幕，從結果開的閱讀器填滿視窗，不再縮在卡片裡（回饋 #91）。

### 模組（新功能）
- 新的模組格式（3.0）：支援 JSON 請求、漫畫、別名、標籤、ISBN、作者與譯者等資訊。
- 官方模組：古騰堡、青空文庫、Open Library、小説家になろう、Bangumi、AniList、openBD、趨勢。
- 可以從模組倉庫或 `yuedu://module` 連結匯入第三方模組；設定裡有「模組」管理頁。
- 模組的書可以加入書架，在 App 內閱讀、更新章節。
- 模組可以回應搜尋、ISBN 查詢，也可以補齊書籍資料。
- 「資料來源」：依你排的順序，由模組補齊書籍詳情，新增的模組預設勾選。
- 模組的選單參數可以設成跟隨「中繼資料語言偏好推薦」，參數和選項名稱也能翻譯成各種語言。
- 模組更新版本後，不再沿用舊版規則抓的清單快取。

### 書籍資料自動補齊
- 匯入書籍缺封面、簡介、分類時，在前景、Wi-Fi 下自動從 Open Library、模組和來源配置補上空欄位。
- 有 ISBN 的書會查 Open Library；沒有作者的 TXT 也會補作者和封面。
- 補上的封面與簡介可以看到出處，也可以移除。
- WebDAV 書庫在 Wi-Fi 前景自動建立索引，並讀取 EPUB 的書名、作者、封面。

### 閱讀器
- 閱讀介面只留「現代」：底部是兩個同樣大小的浮動膠囊，一個是上一章／進度／下一章，一個是目錄、深色、聽書、主題和更多（書籤、AI）。書籍卡片延展到整個寬度。
- 全書搜尋：搜尋裝置上整本書的每一章，可以用正則表達式、可以選在替換規則之前搜尋；有搜尋紀錄、逐筆跳轉、命中高亮，並可以回到搜尋前的位置。
- EPUB 可以調整行距、段距和字距；新開關「套用書本間距」：開著照書本 CSS 的間距，關掉就完全用你的設定（回饋 #97）。
- 匯入的書也能換源：匯入的檔案、來源配置、遠端書庫、模組、青空文庫、古騰堡都是同一部作品的版本，從書名膠囊直接換。
- 書在下載或準備時，直接顯示閱讀器自己的全螢幕「載入中…」，畫在閱讀背景上，點一下可以退出閱讀。
- iPhone 橫向與 iPhone Duo：閱讀器依自己的視窗排版，每一側只讓開那一側的安全區；iOS 27.1 只讓開鏡頭那一段；摺疊時的雙頁每頁各有頁眉頁腳。仿真翻頁的雙頁從中間書脊翻。
- 漫畫可以設定預設閱讀模式，沒個別設定過的漫畫照它開（回饋 #37）。
- 光暈預設關閉，可以選顏色。
- 底部對齊：被文字填滿的頁面會把最後一行對齊到頁尾，所有格式都支援，預設開啟。
- 線上章節的彩蛋影片、iframe 網頁可以在章節內直接播放，包含彈幕頁。
- 匯入 Reeden `.red` 主題包。
- 高亮包可以單獨匯入（.red、.qihighlight），可以編輯九宮格切線。正則高亮框會置中在文字上；同步過來的高亮圖片會正確顯示。
- 支援 CSS 邏輯屬性（舊版引擎）。
- 翻書封面時加上光影。
- 氣泡設定分成段評氣泡、本章說、作者說、神評論四頁。每種都有內建「玻璃」範本（起點的版面、系統玻璃效果）；自訂 SVG 範本跟隨閱讀字型、字級和文字顏色，每個範本各自經 iCloud 同步。
- 來源為了卡片截短的評論（例如起点读书的 18 字加「...」），會用正文規則抓到的資料補回全文；更新前已快取的章節要重新整理才會補。
- EPUB 打不開時顯示「無法開啟書籍」，不再出現空白頁或寫入錯誤的進度。
- 只閱讀不會自動加入書架；離開時會詢問「加入書架？」。
- 替換規則可以多選，一次刪除。
- 上下邊距最大可以設到 120pt。
- 修正：
  - 橫排 ruby 注音第二次重畫時往右偏移。
  - 多執行緒同時繪製時注音錯位，以及直排 ruby 的競態。
  - 直排捲動的開啟、存進度、跳章精準到欄。
  - 捲動模式段落與欄距在區塊交界處跑掉。
  - iPad 邊距從邊緣起算，雙頁只有一組頁眉頁腳。
  - 視窗化 iPad／分割畫面依閱讀器自己的視窗排版，視窗改變時重新排版。
  - 滑動中不再刷新畫面或切換主題。
  - 替換規則改在顯示時套用，而且不套在標題上；Markdown 的替換規則逐段套用。
  - 選取顏色經同一條色彩轉換路徑，顏色一致。
  - 漫畫來源圖片解碼與條漫位置。
  - 段評氣泡被擠到下一行時，上一行不再被拉得很開；選取、高亮、點擊和行內有背景或框線的文字，都對齊實際畫出來的位置，不再偏移。
  - 段評氣泡放不下時，先把那一行的全形標點擠緊騰出位置，讓行尾的字和氣泡留在同一行；真的擠不下才一起換行（橫排）。
  - 有段評氣泡的那一行，上方不再多出一截空白，行距和其他行一致。
  - 起点「热评」卡片的短評論（例如「666」「还只是这一批」）不再被當成評論數刪掉，卡片照樣套用閱讀器的範本。
  - 仿真翻頁的背面、開書轉場和自動閱讀畫面裡，玻璃樣式的評論卡片不再變成一整塊白色。
  - 閱讀設定的「匯入字體」會打開檔案選擇器，以前點了沒有反應。
  - 登入帳號同步後，上下邊距不再被改回同一個值。
  - 只有本章說卡片的頁面，點旁邊空白可以翻頁（回饋 #86）；捲動模式點行間空白會叫出選單，不再打開段評。
  - 段評氣泡和那一行的文字對齊，不再浮在上面（回饋 #87）；自訂 SVG 的段評氣泡不再卡住畫面。
  - 閱讀選單上方的玻璃跟著閱讀主題的深淺，底欄改為滑入滑出（回饋 #78、#81）。
  - 目錄重新整理時，來源插入新章節，閱讀位置和書籤會跟著移動，不再退回上一章（回饋 #95、#96）。
  - 瀏覽器引擎的捲動模式，存進度不再每次往上跑一行。
  - iOS 17 開機後第一次從書架開書，會被彈回書架。
  - 全書搜尋重新搜尋或清除時閃退。
  - 漫畫的閱讀模式加入書架後不再遺失（回饋 #74）。

### 來源配置相容性
- 支援 legado-E 的 callBackJs 事件，修正段評開啟白屏。
- 段評網頁載入時不再整片白：載入畫面會留到網頁真正畫出來為止（例如書山聚合要先等評論請求回來）。
- 加入 legado 的 tripleDES 輔助函式。
- `java.ajaxAll` 在 header 尚未快取時卡 30 秒、回傳空內容的問題已修正（段評一直載入不完可能是這個原因）。
- 帶 JSON 選項的網址一律走執行環境處理；`ajaxAll` 裡需要 JS 的網址不再卡 30 秒。
- 來源的 jsLib 在執行環境準備好之後才執行，請求會經過偵錯記錄和快取。
- 依 Legado 修正多項規則行為：
  - 目錄下一頁規則讀成網址清單，修正大型目錄當機；下一頁回傳錯誤時，其他頁的章節照樣保留。
  - 相對連結保留 `,{…}` 請求選項，略過 javascript 連結。
  - 預設語法的取值合併所有結果，修正正文只顯示第一段（約 1,300 個來源中的 106 個受影響）。
  - 發現頁的下拉選單會記住你的選擇。
  - `@css:` 開頭的規則片段一律照 CSS 讀。
  - 網址的 charset 選項也用來解碼回應，修正 Big5 頁面被誤判成 GBK。
- 拒絕過大或非 UTF-8 的來源檔匯入。
- 圖片解碼的 JS 改在來源自己的執行環境裡跑。
- 來源檢查與請求造成的大量磁碟寫入已消除。
- 正文裡多次提到別的章節（例如「第三章」）的章節，不再一直停在載入中（回饋 #89）。
- 換源或目錄更新後重新對齊章節：認得「12、」這種標題，也分得出「標題12」和「標題21」。

### 效能
- 書架：未改變的格子不重繪，排序結果重用。
- 大量來源：來源庫在背景讀取，以 ID 查找。
- 捲動時不再每一幀寫入畫面狀態。
- 朗讀時 App 根畫面不再每句重繪。
- 網路封面存到磁碟，被清掉的不必重新下載；畫面已持有的封面優先顯示。
- 線上書目錄不再每次啟動重寫全部快取。
- 本地漫畫直接從壓縮檔讀取頁面。
- 青空文庫每次搜尋只查一次，在背景執行。
- 目錄沒有變動時不再重寫（大書架啟動刷新時曾在一分鐘內寫入 1 GB）。
- 大量訂閱重新整理時，文章檔只寫一次。
- 書源檢查不再拿資源正則比對整頁（單一頁面曾耗掉 80 秒 CPU）。
- 段評整理和沒有正文規則時的正文擷取，改成只走一遍頁面，長章節快很多。
- iCloud 合併和書架寫入不再卡住主執行緒，修正切到背景時被系統終止。
