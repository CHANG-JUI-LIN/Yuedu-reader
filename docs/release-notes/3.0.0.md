# 閱讀 3.0.0 更新日誌（自 2.0.7 起）

範圍：2.0.7 最後一個 build（build 9，`0c3f6c76`，2026-10-08）之後到 main 上的所有提交，共 619 個。2.0.8 沒有發佈過，它的內容併進這一版。

---

## App Store「新功能」（可直接貼上）

閱讀 3.0 是一次大改版：書不再分散在各個來源裡，而是以「作品」為中心，集中在同一個地方探索、搜尋和管理。

【全新分頁】
・分頁改成：書架、探索、資源庫、搜尋、設定
・新增「資源庫」分頁：來源配置、遠端書庫（WebDAV／OPDS／Calibre）、訂閱、模組都收在這裡

【探索】
・探索首頁可以自己編排：新增、刪除、調整欄目順序，有八種呈現方式可選，每種都有即時預覽
・新增「為你推薦」：依你讀過的書，在本機排序推薦，不上傳閱讀紀錄
・新增「AI 推薦」，附推薦理由
・新增「繼續閱讀」卡片、精選、專題集合、系列下一本

【作品詳情】
・每本書都有一頁「作品詳情」：簡介、目錄、同系列、同題材作品、作品資訊
・開啟時自動找出你已啟用的來源裡有哪些能讀這本書

【搜尋】
・一次搜尋書架、來源配置、遠端書庫、公有書庫和 Open Library，結果合併成作品清單
・依類型分組篩選，結果會自動載入到底

【模組】
・新的模組系統：古騰堡、青空文庫、Open Library、小説家になろう、Bangumi、AniList、openBD 都是官方模組
・可以匯入第三方模組，也能從模組加書上書架、直接閱讀
・自動補齊書籍資料：缺封面、簡介、分類時，從模組和 Open Library 自動補上

【閱讀】
・頁面底部對齊，文字填滿整頁
・線上章節裡的影片和網頁可以直接在章節內播放
・修正 ruby 注音重畫時位置跑掉、直排捲動跳位、iPad 邊距等排版問題
・匯入 Reeden 主題包與高亮包，可以編輯九宮格框

【其他】
・新的「回饋中心」：可以雙向回覆，附截圖回報問題
・AI 摘要、翻譯、人物分析速度大幅提升
・Widget 與即時動態支援五種語言
・大量效能與穩定性改進

## 完整更新內容

### 分頁與架構
- 分頁改為 書架・探索・資源庫・搜尋・設定。RSS 不再是獨立分頁，訂閱移到資源庫。
- 新增「資源庫」分頁，參考圖式卡片，有格狀和列表兩種顯示。來源依分組排列，可以搜尋。
  - 收納來源配置、遠端書庫、訂閱、模組。
  - 右上「•••」可以新增和管理來源。
- 「遠端書庫」整合到設定裡集中管理：WebDAV、OPDS、Calibre 連線。
- 來源配置管理在所有 iOS 版本都改成推入頁面，不再用 sheet，修正 iOS 17 上匯入按鈕失效的問題。
- 中文介面統一稱「來源配置」，其他語言稱 Source。

### 探索
- 探索的根頁就是首頁，可以直接在首頁底部進入「編輯首頁」，新增、刪除、排序欄目。
- 八種呈現方式：大型閱讀卡片、精簡閱讀卡片、橫向單排書架、多行橫向輪播、固定封面網格、圖文資訊清單、精選（一頁一本並附分類）、專題集合（書單）。選擇時有即時預覽，每種版面配合適的範例封面。
- 「首頁配置」取代舊的自訂頁面，可以有多組首頁，從探索右上角的首頁配置按鈕切換，每組可以設自己的照片。
- 公有書庫有自己的首頁欄目，例如新上架作品。
- 新欄目：繼續閱讀（Apple Books 式卡片）、系列下一本、精選書單、訂閱的最新文章、古騰堡熱門。
- 「為你推薦」：記錄你開過的書屬於哪些分類（只存在本機），在本機排序推薦。每個分類一天只請求一次，冷啟動請求數減半。
- 「AI 推薦」官方模組：首頁欄目和獨立頁面，作品詳情顯示推薦理由；找不到可讀來源時會標示「未找到可用來源」。
- 下拉重新整理會一併抓取訂閱內容，「查看全部」直接開啟訂閱。
- 聚合設定改成 Emby 式首頁設定：首頁欄目、書庫順序、偏好閱讀語言、「顯示在最新」、「隱藏已讀」。
- 刪除舊的探索設定和範圍切換，工具列只留一個「•••」。

### 作品詳情
- 從書架、探索、搜尋、資源庫打開任何一本書，都進同一頁「作品詳情」。
- 版面依序是：封面主視覺、簡介、作品關聯、作品資訊。主要操作只有一個，「繼續閱讀」的進度直接寫在按鈕上。
- 打開就讀取目錄，目錄章節會跳到正確的錨點。
- 同系列：主視覺標出系列名，下方接著列出各卷。
- 同題材作品：標題旁可以選要看哪個分類。
- 打開時會在已啟用的來源中找這本作品，列出能讀的來源與版本。
- 書架上那本的書名、作者、封面、簡介優先顯示；手動修改的簡介會保留。
- 「開始閱讀」和「加入書架」永遠左右並排。

### 搜尋
- 一次搜尋所有地方，結果依作品合併成一張清單：
  - 書架（邊打字邊找）
  - 來源配置
  - OPDS／Calibre 遠端書庫
  - 古騰堡、青空文庫
  - Open Library
  - 模組
- 依類型分組，有「類型」篩選。
- 不再分頁：自動抓完所有結果，會依手機溫度和低耗電模式調整速度。
- 能分辨「來源搜尋失敗」和「沒有結果」，失敗會記錄下來方便診斷。
- 換源、換封面改用作品比對規則，配對更準。
- 「數據來源」列出每個來源的結果數，可以分用途勾選。

### 模組（新功能）
- 新的模組格式（3.0）：支援 JSON 請求、漫畫、別名、標籤、ISBN、作者與譯者等資訊。
- 官方模組：古騰堡、青空文庫、Open Library、小説家になろう、Bangumi、AniList、openBD。
- 可以從模組倉庫或 `yuedu://module` 連結匯入第三方模組；設定裡有「模組」管理頁。
- 模組的書可以加入書架，在 App 內閱讀、更新章節。
- 模組可以回應搜尋、ISBN 查詢，也可以補齊書籍資料。
- 「資料來源」：依你排的順序，由模組補齊書籍詳情，新增的模組預設勾選。

### 書籍資料自動補齊
- 匯入書籍缺封面、簡介、分類時，在前景、Wi-Fi 下自動從 Open Library、模組和來源配置補上空欄位。
- 有 ISBN 的書會查 Open Library；沒有作者的 TXT 也會補作者和封面。
- 補上的封面與簡介可以看到出處，也可以移除。
- WebDAV 書庫在 Wi-Fi 前景自動建立索引，並讀取 EPUB 的書名、作者、封面。

### 閱讀器
- 底部對齊：被文字填滿的頁面會把最後一行對齊到頁尾，所有格式都支援，預設開啟。
- 線上章節的彩蛋影片、iframe 網頁可以在章節內直接播放，包含彈幕頁。
- 匯入 Reeden `.red` 主題包。
- 高亮包可以單獨匯入（.red、.qihighlight），可以編輯九宮格切線。正則高亮框會置中在文字上；同步過來的高亮圖片會正確顯示。
- 支援 CSS 邏輯屬性（舊版引擎）。
- 翻書封面時加上光影。
- EPUB 打不開時顯示「無法開啟書籍」，不再出現空白頁或寫入錯誤的進度。
- 只閱讀不會自動加入書架；離開時會詢問「加入書架？」。
- 修正：
  - 橫排 ruby 注音第二次重畫時往右偏移。
  - 多執行緒同時繪製時注音錯位，以及直排 ruby 的競態。
  - 直排捲動的開啟、存進度、跳章精準到欄。
  - 捲動模式段落與欄距在區塊交界處跑掉。
  - iPad 邊距從邊緣起算，雙頁只有一組頁眉頁腳。
  - 視窗化 iPad／分割畫面依閱讀器自己的視窗排版，視窗改變時重新排版。
  - 滑動中不再刷新畫面或切換主題。
  - 替換規則改在顯示時套用，而且不套在標題上；Markdown 的替換規則逐段套用。
  - 選取顏色經同一條色彩轉換路徑，顏色一致。
  - 漫畫來源圖片解碼與條漫位置。

### 來源配置相容性
- 支援 legado-E 的 callBackJs 事件，修正段評開啟白屏。
- 加入 legado 的 tripleDES 輔助函式。
- `java.ajaxAll` 在 header 尚未快取時卡 30 秒、回傳空內容的問題已修正（段評一直載入不完可能是這個原因）。
- 帶 JSON 選項的網址一律走執行環境處理。
- 拒絕過大或非 UTF-8 的來源檔匯入。
- 圖片解碼的 JS 改在來源自己的執行環境裡跑。
- 來源檢查與請求造成的大量磁碟寫入已消除。

### AI
- 每個功能各自決定要不要思考；DeepSeek 輸出上限提高到 64K，修正回答被截斷。
- 全書摘要 48K 一批、三批同時；整章翻譯三批同時；人物分析每次讀 4,000 字。速度大幅提升。

### 回饋與診斷
- 「診斷與回報」改成雙向的「回饋中心」，可以看到回覆、附截圖回報問題。
- 卡頓回報可以在不拿到使用者手機的情況下說明原因。
- 診斷記錄跨啟動連續編號；當機回溯順序正確。

### iCloud 與同步
- 回到前景時同步，並在背景任務下完成。
- 高亮圖片失敗不再擋住書架同步。
- 同步過來的 EPUB 在檔案到達後讀取書籍資訊。

### 效能
- 書架：未改變的格子不重繪，排序結果重用。
- 大量來源：來源庫在背景讀取，以 ID 查找。
- 捲動時不再每一幀寫入畫面狀態。
- 朗讀時 App 根畫面不再每句重繪。
- 網路封面存到磁碟，被清掉的不必重新下載；畫面已持有的封面優先顯示。
- 線上書目錄不再每次啟動重寫全部快取。
- 本地漫畫直接從壓縮檔讀取頁面。
- 青空文庫每次搜尋只查一次，在背景執行。

### 聽書
- 微軟線上語音改用新版驗證 token。
- 關閉閱讀器後朗讀繼續；已關閉的閱讀器會正確釋放。
- 同時只有一個迷你播放器。

### 在地化與無障礙
- Widget 與即時動態支援繁中、簡中、英文、日文、韓文。
- Info.plist 的文件類型名稱也翻譯成五種語言。
- 數量改成整句翻譯，英文複數正確。
- 選單開啟時，閱讀頁面不再搶走 VoiceOver 焦點。

### 穩定性
- 程式碼全面改為 Swift 嚴格並發檢查，消除大量潛在的資料競爭。
- 修正大書架或大量目錄時主執行緒卡頓、舊快取目錄被誤刪等問題。
