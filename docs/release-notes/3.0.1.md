## App Store「新功能」（可直接貼上）

【新功能】
・可以匯入 MOBI 和 AZW3（Kindle）電子書，匯入時自動轉成 EPUB
・支援影片類來源配置：每部影片有自己的詳情頁，選集附上每集的畫面和片長，用 App 內建的播放器播放
・同一本書裡的直排和橫排章節，各自依自己的方向排版
・新增「閱讀時螢幕常亮」，可透過 iCloud 同步
・正文字級最大到 60pt
・目錄顯示章節的更新時間，並標出還沒快取的章節
・每本線上書都能開啟、複製來源網頁，方便除錯

【修正】
・仿真翻頁偶爾跳頁、點按翻頁沒有動畫
・翻了幾頁後又被拉回開書的位置
・捲動模式：進度條放開後卡住、章節開頭頁眉空白、沒有文字的章節一直抖動
・條漫閃黑、頁與頁之間出現細線，長時間閱讀越來越卡
・清除封面快取後封面消失；匯入書被刪掉的封面會自動找回
・探索返回時畫面閃一下；iOS 17 上往上捲會被拉回
・iOS 17 上隱藏或顯示分頁後，其他分頁變成空白或閃退
・大量來源配置相容性修正
・VoiceOver：閱讀進度條上下滑動一次換一章

## 完整更新內容

### MOBI／AZW3 匯入
- 可以匯入 MOBI 和 AZW3（Kindle 格式）。匯入時轉成 EPUB，原檔保留在旁邊；閱讀、同步、搜尋都跟一般 EPUB 一樣。
- 支援 MOBI 6 和 KF8（AZW3），內嵌字型和目錄都會帶過來。KF8 的固定版面書目前先以重排方式顯示。
- 每個匯入入口都認得這兩種格式：本機匯入、Calibre 無線傳輸、遠端書庫（OPDS、WebDAV）的書與詳情頁、上傳。
- 匯入失敗時會說明原因。
- 從其他 App「用其他 App 開啟」匯入後，不再留下多餘的副本。

### 影片來源
- 支援 Legado 的影片類來源配置（類型 4）。
- 影片有自己的詳情頁：
  - 海報從頂端鋪滿整個寬度，淡入頁面背景色；整頁用海報底部的顏色。
  - 一個播放鍵，從上次看到的那一集繼續。
  - 選集用「線路」選單切換，每一集附上自己的畫面和片長，正在看的那集有白框。
  - 下方是同類型作品的海報牆。
  - iPad 和寬視窗上海報一樣橫跨整頁。
- 播放器：上一集、播放／暫停、下一集、時間軸、倍速、長按 3 倍速、AirPlay、畫面填滿切換、子母畫面、選集。
  - 一條線路播完，自動接下一條線路的第一集。
  - iPhone 上以橫向開啟，直式影片自動轉回直向。
  - 播放失敗的集數會重新解析一次。
  - 開始播放影片時，有聲書暫停、朗讀停止。
- 聚合來源（UAA、光遇聚合、大灰狼、七猫-OE、番茄四合一、书山 短剧）的影片一律在 App 的播放器播放，不再開成文字書、有聲書或網頁；15 秒內找不到影片會直接告知。
- 剛好網路不好而沒拿到的集數畫面，之後會再試一次。

### 閱讀
- 同一本 EPUB 裡的直排和橫排章節，各自依自己的書寫方向排版。例如 Calibre 轉出來的直排書，最後附的橫排目錄不再被排成直排；翻頁方向仍以整本書為準。
- 捲動模式也照章節的書寫方向：連續同方向的章節是一段，捲到段落結尾就接上下一段。目錄、書籤、連結、搜尋、上一章／下一章和進度條跳轉都會先切到目標所在的那一段；自動捲動在段落結尾停下。
- 開書動畫判斷直排的方式跟閱讀器一致，不再因為 CSS 裡隨便一條直排規則就把整本書當成直排。
- 新增「閱讀時螢幕常亮」（閱讀設定 → 亮度，預設關閉），會透過 iCloud 同步到其他裝置（回饋 FB-60）。
  - 自動閱讀和朗讀不再互相把螢幕關掉：例如自動閱讀還在跑時停止朗讀，螢幕不會再暗掉。
- 正文字級最大到 60pt。
- 內建「玻璃」段評卡片跟著閱讀器選的字型（回饋 FB-42）。
- 目錄標題、空白頁的標題、說明和按鈕，以及搜尋結果，都跟著全域字型（回饋 FB-41）。
- 整頁插圖前面不再多出一張空白頁（YueduCoreText 0.10.2）。
- 只有插圖的頁面有自己的閱讀位置：仿真往前翻不再跳過一頁文字，往回翻也不會停在同一張圖上（YueduCoreText 0.11）。已存的書籤和閱讀位置會自動換算。
- 封面在目錄第一項之前、或結尾還多一頁目錄的書：
  - 第一章的「下一章」不再是書末頁。
  - 捲動模式的進度條可以拉到最後幾章。
  - 朗讀不會在目錄的最後一項就停下。
  - 筆記、高亮、預載和翻譯不再漏掉最後幾章。
  - 重新打開時回到正確的章節。
- 用「用其他 App 開啟」打開的閱讀器、看圖片預覽時底下的閱讀器：切到背景再回來時，閱讀時間照常計算，深淺色跟著系統切換，背景裡不再讓螢幕保持亮著；同步、儲存等背景工作也照常執行。

### 仿真翻頁與閱讀位置
- 從背景回來後，仿真翻頁不再跳頁或跳回上一章（回饋 FB-118）。
- 點按翻頁不再偶爾失去仿真動畫；翻得比下一章載入還快時也有動畫。
- 翻了幾頁之後，不會再被拉回開書時的位置（回饋 FB-112）。

### 捲動模式
- 章節開頭不再留一條空白的頁眉，頁眉照樣顯示正文的欄位（回饋 FB-115）。
- 只有地圖、封面或影片的章節，不再讓畫面原地抖動、無法捲動。
- 閱讀進度條放開手指後，預覽和進度不再停在放開的位置。拖曳途中被系統打斷時，不會跳章。

### 目錄
- 來源有提供時，顯示每章的更新時間（回饋 FB-85）。
- 標出還沒快取的章節（回饋 FB-88）。
- 目錄的搜尋欄一直留在畫面上（回饋 FB-46）。
- 打開目錄時直接捲到目前章節，不再慢一拍。

### 來源網頁與除錯
- 每本有來源的線上書，作品詳情的「更多」都有「複製書籍網址」「複製目錄網址」和「開啟網頁」；以前只有少數來源有（回饋 FB-84、FB-102、FB-104、FB-105）。
- 網頁視窗多了「複製網址」，複製的是跳轉後的實際網址。
- 閱讀器的「更多」多了一組：「複製正文網址」和「調試正文」（直接打開調試規則並填好這一章的網址）。

### 漫畫
- 條漫載入前後章節時，已載入的圖不再閃黑（回饋 FB-114）。
- 條漫只保留前後三章，長時間閱讀不再越來越卡；下一章只預取一次。
- 翻到已經在記憶體裡的圖，立即顯示，不再先閃一下黑底。
- 條漫頁與頁之間不再出現細線（回饋 FB-127）。

### 探索、資源庫與書架
- 從其他頁面回到探索時，已載入的欄目不再閃一下（回饋 FB-38）。
- iOS 17.0 上探索往上捲不再被拉回「編輯首頁」（回饋 FB-120）。
- iOS 17 上從探索打開的閱讀器，跟書架一樣是沉浸式（回饋 FB-100）。
- 資源庫和來源配置管理的「支援發現」數量一致（回饋 FB-123）。
- iOS 17 上在外觀主題的「底部分頁」隱藏或顯示分頁後，其他分頁不再變成空白；iOS 17.0 上不再因此閃退。
- 從別處補上的簡介，跟著「中繼資料語言偏好推薦」轉成繁體或簡體。
- OPDS 書庫的卡片用完整封面，不再放大縮圖。
- 從來源頁面閱讀、沒有加入書架的書，保留原本的閱讀模式（回饋 FB-101）。
- 換源後留下的版本，從來源頁面直接閱讀再關掉時，不再被刪除（連同進度、書籤和閱讀模式）。

### 封面
- 「清除封面快取」後會重新抓回封面，不再全部變成預設封面（回饋 FB-116）。
- 清除封面快取不再刪掉匯入書（EPUB、漫畫、PDF、有聲書）自己的封面；3.0.0 已經刪掉的，會從書本檔案找回來。

### 來源配置相容性
- `java.put` 存的值跟著它所在的搜尋／發現結果、書、頁和章節，不再互相覆蓋。
- 詳情、目錄和正文的請求網址，用的是這本書自己的變數。
- 搜尋網址模板裡的逗號（例如 `{{key,GBK}}`）不再把網址截斷。
- 每個來源的執行狀態各自儲存，大量來源配置時不再一直重寫整個設定檔。
- 腳本裡的 jsoup、StrResponse 和 Java String 行為跟 Legado 一致，修正六種 Legado 不會出錯的腳本錯誤（回饋 FB-105）。
- 登入腳本用 `setVariable` 存的值，會重新載入已開啟的發現頁，例如漫蛙（回饋 FB-73）。
- jsoup 的 Elements 支援 `toArray()` 和索引，例如猕猴桃漫画的發現頁不再顯示「暫無發現內容」（回饋 FB-124）。

### 來源檢查
- 有聲來源讀取章節網址；含 `~` 的選擇器不再極慢。
- 檢查會依 CPU 用量自動放慢，大量來源配置時不再因為超過系統限制被終止。

### 同步與帳號
- 來源配置沒有變動時不再寫檔，上傳前先抓取，大幅減少磁碟寫入。
- 兩台裝置匯入同一包來源配置時，每台保留的是同一份。
- 刪除帳號時先撤銷 Apple 授權。修正經由閘道伺服器刪除帳號時一定失敗、資料只刪了一半的問題；經由閘道綁定郵件也能正常使用。

### 無障礙
- 閱讀進度條的 VoiceOver 上下滑動，一次換一章。以前調整了也不會跳到那一章。
- 調試規則的關閉按鈕，VoiceOver 唸「關閉」。

### 效能
- iOS 27 上切到背景時，系統查詢 SpringBoard 類別不再掃描整個 App。
- 快取章節不再重寫整本書的目錄：以前 2000 章的書每快取一章，就要重寫一次 385 KB。
- 作品比對與模組清單的處理移到背景，或改成一次轉換。
