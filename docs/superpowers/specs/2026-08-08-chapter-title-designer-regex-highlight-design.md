# 章節標題設計器與正則高亮設計規格

日期：2026-08-08

## 摘要

本功能補齊「章節標題高級 CSS 樣式」的視覺設計、圖層、素材與原始碼編輯能力，並把目前閱讀設定中的「對話文字高亮」升級為「正則高亮」二級頁。兩者共用一套可驗證的樣式模型、圖片素材庫與 CoreText 裝飾繪製能力。

閱讀頁繼續使用 SwiftUI、UIKit 與 CoreText，不引入 WebView。原始碼編輯器支援明確界定、可雙向轉換的 HTML/CSS 子集；不支援的語法必須在套用前指出行列與原因，不得靜默忽略。

## 目標

1. 為章節標題提供完整的視覺設計器：元素、圖層、畫布、樣式、圖片資源、復原／重做與原始碼。
2. 讓視覺設計、原始碼預覽與真正閱讀頁共用同一套 CoreText 編譯、排版與繪製行為。
3. 把「對話文字高亮」改名為「正則高亮」並移至二級頁，同時加入內建規則、自訂規則、樣式編輯、背景圖片、邊距和 CSS。
4. 支援 TXT、線上小說與 EPUB，以及分頁／捲動、橫排／直排、淺色／深色模式。
5. 保存並匯出使用者圖片；樣式包換機或分享後能完整還原。
6. 保持閱讀位置、搜尋、文字選取、TTS、Dynamic Type 與 VoiceOver 行為正確。

## 非目標

1. 不支援任意瀏覽器 HTML、JavaScript、遠端網頁或完整 CSS 規格。
2. 不在閱讀頁或預覽中使用 WebView。
3. 不讓任意正則邊距重新編排原書正文；背景框邊距只影響裝飾繪製範圍。字體大小和行高等文字屬性仍會正常觸發重新分頁。
4. 不提供不同機型各自維護的設計。畫布以相對座標自適應視窗尺寸。
5. 不為橫排與直排保存兩套獨立畫布。直排由同一份設計自動轉換。

## 核心決策

### 單一結構化來源

視覺編輯器不直接把任意 HTML 當作內部狀態。畫布、圖層、樣式與素材引用先保存成版本化結構，再由編譯器輸出 CoreText 所需的文字屬性和裝飾繪製指令。

原始碼頁顯示此結構的標準化 HTML/CSS 表示。使用者套用原始碼時，解析器必須先完整轉回結構化模型；只有全部驗證成功才原子替換草稿。這能確保視覺介面、原始碼與閱讀頁可往返且一致。

### 共用樣式能力

章節標題與正則高亮共用下列能力：

- 淺色／深色顏色與圖片變體。
- 字體、字號、字重、字距、行距、對齊與文字裝飾。
- 背景色、漸層、圖片、透明度、邊框、圓角與陰影。
- 圖片素材匯入、解析、縮圖、引用、匯出與刪除保護。
- CSS 宣告驗證與標準化。
- CoreText 橫排及直排裝飾繪製。

章節畫布另外支援相對位置、尺寸、旋轉與圖層順序；正則高亮不支援任意絕對定位。

## 章節標題設計器

### 進入方式與提交語意

現有「章節標題樣式」頁保留。啟用「高級 CSS 樣式」後顯示「編輯設計」入口，進入全螢幕編輯 sheet。

- leading 使用 `xmark` 取消，捨棄本次所有未套用草稿。
- trailing 使用 `checkmark` 套用，將草稿作為一次設定變更提交。
- 復原與重做只操作當前草稿，不修改已套用設定。
- 套用後由既有不可變 render-settings snapshot 觸發相關引擎重新排版或重繪。

### 畫布

畫布使用真正的 CoreText 編譯及裝飾繪製器預覽，支援：

- 點選圖層。
- 拖曳位置。
- 八方向縮放。
- 旋轉。
- 對齊參考線與吸附。
- 復原／重做。
- 淺色／深色預覽。
- 橫排／直排預覽。

位置與尺寸以畫布寬高的標準化比例保存。字號、線寬、圓角和陰影半徑保存為閱讀尺度值，不因螢幕寬度等比放大到失去可讀性。

橫排設計轉為 `vertical-rl` 時共用相同圖層：編譯器交換並映射主要／交叉軸，文字圖層使用直排文字方向，圖層順序不變。圖片、色塊和線條保留各自旋轉值；使用者可在直排預覽中檢查結果，但不產生第二份直排資料。

### 元素

設計器提供：

- 章節數：`{number}`。
- 章節名：`{name}`。
- 原始標題：`{title}`。
- 自訂文字。
- 裝飾線：以預設裝飾線型建立，可再調整。
- 一般線條：直線圖層，可設定方向、粗細、端點及樣式。
- 色塊：矩形或圓角背景圖層。
- 圖片：引用共用素材庫的圖片圖層。

`{name}`、`{number}` 保持與目前模板相容；`{title}` 為新增的完整原始章節標題。字體插入動作輸出受支援的 CSS font token，不把 PostScript 名稱硬寫進文字內容。

章節數、章節名與原始標題等動態圖層可以隱藏。刪除最後一個動態標題圖層時，設計器保留可從「元素」重新加入的能力，不讓模板永久失去動態內容來源。

### 圖層

圖層清單支援：

- 拖曳排序。
- 顯示／隱藏。
- 鎖定／解鎖。
- 複製。
- 刪除。
- 重新命名。
- 從清單選取並同步畫布選取狀態。

鎖定圖層不能在畫布上移動、縮放或旋轉，但仍能從檢查器檢視資料。圖層狀態不得只靠顏色表示。

### 樣式檢查器

依元素類型顯示適用控制：

- 位置、尺寸、旋轉及層級。
- 水平／垂直文字對齊。
- 字體、字號、字重、字距、行距及文字裝飾。
- 淺色／深色文字色。
- 淺色／深色填色、漸層或背景圖片。
- 透明度。
- 四邊內距與外距。
- 四邊邊框、圓角和陰影。
- 圖片填滿、適應、平鋪、拉伸及焦點位置。

所有數值控制必須有直接輸入與可調整控制，VoiceOver 不依賴畫布手勢也能精確修改位置、尺寸、旋轉與排序。

### HTML/CSS 原始碼

原始碼編輯器提供插入章節名、章節數、原始標題、章節名字體及章節數字體的動作。輸出是穩定、可讀、可再次解析的標準格式。

允許標籤：

- `div`
- `p`
- `span`
- `img`
- `hr`

允許的章節畫布 CSS 類別：

- 定位與尺寸：`position: absolute`、`left`、`top`、`width`、`height`、`box-sizing`。
- 文字：`text-align`、`font-family`、`font-size`、`font-weight`、`font-style`、`letter-spacing`、`line-height`、`color`、`text-decoration`。
- 盒模型：`margin`、各邊 margin、`padding`、各邊 padding。
- 裝飾：`background-color`、受管理的 `background-image`、`background-size`、`background-position`、`background-repeat`、`border` 與各邊 border、`border-radius`、`box-shadow`、`opacity`。
- 變換：單一 `rotate(...)`。不接受任意 transform matrix、skew 或 perspective。

不支援 selector cascade、flex、grid、float、script、iframe、遠端 URL、動畫、transition 或偽元素。解析器需顯示錯誤行列、屬性名稱與可採用的替代方式。套用失敗時保留原始碼草稿和先前有效設計。

### 章節標題套用範圍

- TXT、線上小說與 Markdown 的 App 產生章節開頭使用完整設計器樣式。
- EPUB 中已被閱讀器辨識為章節開頭的語意標題使用完整設計；同章其他 publisher-authored heading 維持書籍 CSS，不被全域替換。
- 章節標題底層文字保留在 attributed string 中供搜尋、選取與無障礙使用；畫布繪製只抑制重複的預設 glyph 繪製，不把標題轉成圖片。
- 分頁預留畫布實際高度，位置仍以 `(spineIndex, charOffset)` 保存。

### 現有功能相容

下列功能保持可用：

- 高級 CSS 開關。
- 內建預設與我的預設。
- 淺色／深色預覽。
- 標題大小、上方間距及與正文間距。
- 樣式匯入、匯出及恢復官方預設。
- 目前 `{name}`、`{number}` HTML 模板的解碼與轉換。

## 正則高亮

### 導航與列表

閱讀設定「閱讀裝飾」中的「對話文字高亮」改名為「正則高亮」，並改為 `NavigationLink`。二級頁使用系統返回和 `.inline` 標題。

頁面包含：

- 全域開關及關閉時的說明。
- 已啟用、內建、自訂數量摘要。
- 內建規則區。
- 自訂規則區。
- 新增規則動作。

規則列顯示啟用開關、辨識色、名稱、內建標記、正則摘要、複製及詳情入口。自訂規則可以刪除和拖曳排序；內建規則名稱及 pattern 固定且不可刪除，但可啟用、停用、修改樣式及複製成自訂規則。

### 內建規則

首次建立下列五條內建規則：

1. 中文彎雙引號，橙色，預設啟用：`“[^”\n]*”`
2. 中文彎單引號，藍色，預設啟用：`‘[^’\n]*’`
3. 中文直角引號，綠色，預設啟用：`「[^」\n]*」`
4. 中文雙直角引號，紫色，預設啟用：`『[^』\n]*』`
5. 提示方括號，紅色，預設停用：`【[^】\n]*】`

辨識色只是預設淺色樣式；每條規則可分別調整淺色與深色。規則狀態同時以名稱、內建標記和開關表達，不只靠顏色。

### 規則編輯

規則編輯是可取消的 modal task，使用四個分頁。

#### 基礎

- 名稱。
- pattern。
- 大小寫選項。
- 是否允許跨段。
- 即時測試文字與命中預覽。
- 淺色／深色文字色。
- 跟隨閱讀字體或自訂字體。
- 自訂字號、字重、字體樣式、底線及刪除線。

內建規則的名稱和 pattern 唯讀。無效 pattern 顯示錯誤位置且不能儲存。啟用「匹配不跨段」時，規則逐段執行，換行及段落分隔符不進入候選範圍；關閉時以整章最終文字執行。

#### 背景圖

- 無背景、純色、漸層或圖片。
- 淺色／深色變體。
- 圖片填滿、適應、平鋪或拉伸。
- 圖片焦點位置及透明度。
- 從共用素材庫選擇或匯入。

#### 邊距

- 背景框四邊內距。
- 相鄰背景片段的視覺間隔。
- 四邊邊框。
- 圓角。
- 陰影。

上述邊距改變裝飾框範圍，不改動原文字符位置。文字字號或行高等文字屬性會參與排版並觸發重新分頁。

#### CSS

CSS 頁編輯單一規則的 declaration block，不接受 selector 或 HTML。支援文字、背景、盒模型、邊框、圓角、陰影、透明度與文字裝飾子集；不支援絕對定位。與前三個分頁雙向同步，解析採全有或全無。

### 匹配與疊加語意

1. 在最終 attributed string 完成 HTML/TXT typography 後執行匹配，確保 UTF-16 range 對應穩定。
2. 評估順序固定為內建規則顯示順序，再接自訂規則排序。自訂規則可在自己的區段拖曳排序。
3. 所有匹配都參與結果，不採第一條命中即停止。
4. 引擎依所有匹配邊界切成最小非重疊區段。
5. 每個樣式欄位為 optional；依規則順序合併，後面的規則覆蓋同名欄位。
6. 非衝突效果累加。文字底線與刪除線可共存；陰影可以依序疊加。單值欄位如文字色、字體、背景色、背景圖、圓角及同一邊框由後面的規則覆蓋。
7. 相鄰且最終樣式完全相同的區段合併，避免產生不必要的 CoreText runs。

### 渲染流程

`RegexHighlightEngine` 負責編譯、匹配與合併，不由 SwiftUI view 執行。輸出分成：

- 原生 CoreText 文字屬性：文字色、字體、字號、字重、字體樣式、字距、行高、底線與刪除線。
- 自訂裝飾 attribute：背景色、漸層、背景圖、邊框、圓角、陰影與框內距。

橫排與直排繪製器都讀取同一個合併裝飾 attribute，再使用各自的 glyph/line rect 幾何繪製。換主題、更新規則或 fast appearance recolor 時，先移除舊正則高亮屬性，再依當前不可變設定快照重新匹配，不能保留舊顏色或舊背景。

套用範圍涵蓋：

- TXT lazy builder。
- 線上 HTML 與 RenderableNode builder。
- EPUB HTML builder。
- 分頁與捲動。
- 橫排與 `vertical-rl`。

## 圖片素材

### 儲存

`ReaderStyleAssetStore` 是唯一素材入口。匯入來源為相簿與檔案，成功後複製到 App 管理的 Application Support 目錄，以穩定 asset ID 引用，不能持續依賴外部 security-scoped URL。

素材包含：

- 穩定 ID。
- 使用者名稱。
- MIME type。
- 像素尺寸與 alpha 資訊。
- 內容雜湊，用於去重。
- 正規化圖片及縮圖。
- 引用位置。

匯入時先驗證檔案和可解碼像素，再在背景工作中降採樣。最大原始輸入為 20 MB、最大可解碼像素為 80 megapixels、保存長邊上限為 4096 px、縮圖長邊為 256 px。這些限制以共用設定常數定義；錯誤訊息需顯示實際值與限制。含透明度圖片保存 PNG，其他圖片保存高品質 JPEG。

### 引用與刪除

素材頁顯示縮圖、名稱和引用數。刪除未使用素材可直接完成；刪除仍被圖層或規則引用的素材前，顯示受影響項目並要求確認。確認後移除相關圖片引用，但保留其餘樣式，不留下無法解碼的 dangling ID。

### 匯入與匯出

新版使用自訂樣式包，內含：

- 版本化 manifest。
- 章節標題設計或正則設定。
- 實際被引用的圖片檔案。
- 內容雜湊及完整性資料。

樣式包使用現有壓縮依賴建立，匯入時先解到獨立暫存目錄、驗證 manifest、路徑、大小、雜湊與圖片後，再原子搬入素材庫。不得接受 `..`、絕對路徑或符號連結。現有純 JSON 章節樣式繼續可匯入；無圖片的新樣式仍以新版 manifest 表示。

## 持久化與遷移

### 章節標題

`ChapterTitleStyle` 仍是章節標題設定入口，新增版本化設計資料且提供自訂 decoding defaults。舊欄位、舊 `{name}`／`{number}` 模板、內建預設、使用者預設和純 JSON 匯入保持相容。

### 正則高亮

第一次找不到新版 `RegexHighlightConfiguration` 時：

1. 讀取舊 `readerDialogueHighlightEnabled` 作為新版全域開關。
2. 建立五條指定內建規則和預設樣式。
3. 不遷移舊文字色、底色框顏色或底色框樣式。
4. 保存新版設定，後續不再次執行遷移。

舊 key 暫時保留供舊主題／設定檔解碼，不再作為閱讀渲染來源。新版主題或外觀匯出包含正則設定和被引用素材；舊匯出格式仍可解碼，缺少新版資料時不覆蓋既有正則規則。

### 設定快照

閱讀器只接收 `Equatable`、不可變的章節設計和正則設定快照。View 只呼叫 store/coordinator 的單一 use case；圖片解析、正則編譯、快取、匯入、匯出與清理均由 service/domain 層負責。

設定變更分類：

- 只改背景色、圖片、邊框或陰影，且不改幾何或文字屬性時，可走安全重繪路徑。
- 改變字體、字號、字重、字距、行高、章節畫布高度或任何會改變 glyph metrics 的屬性時，必須重新分頁。
- 判斷集中在 render refresh policy，不由各 view 自行決定。

## 原生介面與無障礙

### iPhone

- 章節設計器畫布在上方，元素、樣式、資源、原始碼用底部原生分頁切換。
- 正則高亮使用 pushed `List`／`Form`；規則編輯使用 modal task 和分頁。
- 規則排序使用 `EditButton` 和原生 move 行為。

### iPad

- 依實際 window size 使用自適應雙欄：畫布與檢查器同時顯示。
- Split View、Stage Manager、旋轉及視窗 resize 只改版面，不建立另一套設定。
- 內容寬度使用 `DSLayout` readable width token。

### 通用要求

- pushed detail 與 modal sheet 使用 `.inline` title mode。
- 所有使用者文字經 `localized("...")` 並同步繁中、簡中及英文。
- 顏色、語意字體、間距、圓角及動畫使用 `DS*` token。
- icon-only 按鈕各自提供在地化 accessibility label，裝飾 SF Symbol 隱藏於 VoiceOver。
- 一般 hit region 至少 44×44 pt。
- Slider 的 accessibility label/value 與畫面顯示共用同一計算來源。
- 畫布拖曳、縮放、旋轉及排序都有表單式替代控制。
- 支援最大 Dynamic Type、Bold Text、Increase Contrast、Reduce Motion、Light/Dark。
- 顯示、鎖定、啟用、命中和錯誤狀態不得只靠顏色。
- 套用、刪除、匯入成功與失敗需向 VoiceOver 宣告結果。
- 背景圖片或低對比樣式不得讓必要設定文字失去可讀性。

### 空、載入與錯誤狀態

- 無自訂規則／無素材：圖示、說明與新增動作。
- 圖片解碼、樣式包匯入與原始碼解析：`ProgressView`，長操作可取消。
- 正則錯誤、CSS 錯誤、資源缺失、圖片超限、完整性失敗及匯出失敗：說明發生什麼、錯誤位置／限制及修正方式。
- 低文字／背景對比：顯示非阻斷警告，使用者仍可明確確認套用。

## 安全與效能邊界

- 正則 pattern 長度上限為 2,048 UTF-16 units。
- 單章單規則最多接受 10,000 個 match；超限時該規則在該章停止並記錄可見診斷，不套用未完整計算的部分結果。
- 「不跨段」規則逐段匹配，避免不必要的大範圍回溯。
- 規則依內容、pattern、options 和設定 revision 快取編譯結果；不得為每個 glyph 重新編譯。
- 正則匹配和圖片解碼不在 SwiftUI body 或主執行緒執行。
- 圖片按實際繪製尺寸解碼／降採樣，CoreText render snapshot 不保留多份原始大圖。
- 匯入壓縮包需限制總展開大小和檔案數，並防止 path traversal。
- 發生限制錯誤時不新增 retry、delay 或替代解析路徑。

## 測試與驗收

### 資料與轉換

- `ChapterTitleDesign` 舊／新版本 decoding、sanitization 與相對座標。
- 視覺模型 → 標準 HTML/CSS → 視覺模型 round trip。
- 不支援標籤、屬性、URL、transform 和錯誤行列。
- 橫排 → `vertical-rl` 軸轉換、文字方向、旋轉和圖層順序。
- 舊章節樣式 JSON 與 `{name}`／`{number}` 相容。
- 帶圖片樣式包 round trip、雜湊、去重、缺檔、超限和 path traversal。

### 正則

- 五條內建規則、預設啟用狀態與固定 pattern。
- 全域開關從舊設定遷移，舊顏色不遷移且只執行一次。
- Unicode、emoji、組合字元與 UTF-16 range。
- 跨段／不跨段。
- 無效 pattern、長度限制和 match 數量限制。
- 內建順序、自訂排序、所有匹配疊加、後規則同名欄位覆蓋。
- 底線和刪除線共存、陰影疊加及相同區段合併。
- 主題切換或 fast recolor 先清除舊標記再套用新樣式。

### 渲染

- TXT lazy builder、線上 HTML、RenderableNode 與 EPUB chapter-opening path。
- 分頁、捲動、橫排及直排。
- 章節畫布文字保持可搜尋／選取，畫布高度參與分頁。
- 背景色、漸層、圖片、填滿模式、邊框、圓角及陰影的 rect 幾何。
- 正則字體變更觸發重新分頁，純裝飾變更使用正確重繪路徑。
- 閱讀位置在重新分頁後仍以 `(spineIndex, charOffset)` 恢復。

### UI、在地化與無障礙

- 取消不保存、套用原子提交、復原／重做及未保存離開確認。
- 素材與自訂規則的空／載入／錯誤狀態。
- iPhone、iPad、旋轉、Split View、最大 Dynamic Type 和長在地化字串。
- VoiceOver 的按鈕名稱、狀態、順序、Slider 數值和畫布替代控制。
- 三份 `Localizable.strings` 同步。

### 必跑回歸

實作按任務分段執行直接相關測試，不以 diff 或純 build 取代。至少涵蓋：

- `ChapterTitleAttributedBuilderTests`
- 新增的章節設計模型／codec／asset store 測試類別
- `DialogueHighlighterTests`（升級或改名為正則高亮引擎測試）
- `ReaderRenderSettingsSnapshotTests`
- `AppearanceThemeExportTests`
- `OnlineReaderPipelineUnificationTests` 的直接相關方法
- `CoreTextWritingModeTests`（任何直排繪製修改前、後都執行）
- `ruby scripts/check_localizations.rb`
- `git diff --check`
- 受影響 target 的最小可靠 simulator build

所有相關回歸通過前，不宣稱功能完成或建立實作 commit。

## 完成標準

1. 使用者可完全透過視覺設計器建立包含動態文字、線條、色塊、圖片與淺深色樣式的章節標題。
2. 原始碼在受支援子集內可雙向往返；錯誤不會部分套用。
3. 同一設計在不同視窗尺寸自適應，並在直排閱讀自動轉換。
4. 正則高亮提供五條內建規則、自訂規則、四頁樣式編輯、圖片和 CSS。
5. 重疊匹配全部疊加，後面的規則只覆蓋同名屬性。
6. 舊全域高亮開關被保留，舊顏色／底色不遷移；舊章節樣式及主題檔仍可解碼。
7. 樣式包包含所需圖片，換機匯入後不缺素材。
8. TXT、線上、EPUB、分頁、捲動、橫排和直排的預覽與閱讀頁一致。
9. 無障礙、三語在地化、安全限制和直接相關回歸測試全部通過。
