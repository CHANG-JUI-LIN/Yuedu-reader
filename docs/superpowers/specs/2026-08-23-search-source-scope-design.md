# 搜尋書源範圍設計

## 目標

讓搜尋頁像 Legado 一樣支援可控的書源搜尋範圍：使用者可選擇所有已啟用書源，或永久保存一組自己勾選的書源。搜尋仍沿用既有 `SearchAggregator`，不建立第二條搜尋、解析、快取或結果聚合路徑。

## 設計方向

這是搜尋頁原型。主要使用者流程是先確認搜尋範圍，再輸入書名或作者；視覺上保留使用者提供的頂部膠囊方向，但以原生控制與 Sheet 承載大量書源，維持 iOS 導覽、Dynamic Type、深色模式與 VoiceOver 行為。

## 搜尋頁資訊架構

- 搜尋頁維持現有 inline 標題、系統 `.searchable`、搜尋結果清單及載入／暫停／空結果／錯誤狀態。
- 移除目前只能選「全部」或單一書源的橫向書源膠囊列。
- 在結果區上方放置一個搜尋範圍膠囊控制：
  - 全部模式顯示「全部書源」。
  - 自選模式顯示「已選 N 個書源」。
  - 選取狀態同時使用強調色、文字與勾選圖示，不只依靠顏色。
  - 點擊後開啟搜尋範圍 Sheet。
- 使用者提供的參考圖只決定頂部範圍控制的視覺方向；「精確」、「單源」、「不聚合」、底部自製搜尋欄與齒輪不屬於本次需求，不在此功能加入。

## 搜尋範圍 Sheet

- 使用 `NavigationStack`、inline 標題「搜尋範圍」與原生 `List`。
- leading 為 `xmark` 取消按鈕；trailing 為 `checkmark` 完成按鈕。取消不保存草稿，完成才提交並永久保存。
- 頂部以單一 `Picker` 選取「全部書源」或「自選書源」，避免用多個獨立 Toggle 表達互斥狀態。
- 自選模式顯示所有已啟用書源：
  - 支援 `.searchable` 依書源名稱與 URL 篩選。
  - 點擊書源列切換勾選；選取以勾號、文字狀態與 VoiceOver selected trait 表達。
  - 提供「全選」及「清除」動作。
  - 沒有任何可用選取時顯示 inline 說明並停用完成按鈕。
- Sheet 使用 `DSColor`、`DSFont`、`DSSpacing` 與既有頁面背景語意。所有列明確設定背景，避免主題背景出現意外白色區塊。

## 狀態與持久化

- 新增專責搜尋範圍值型別，表示：
  - `all`：解析為所有已啟用書源。
  - `custom(Set<String>)`：集合內容為使用者選取的 `bookSourceUrl`。
- 使用書源 URL 而非 UUID 作持久識別。書源重新匯入或重建而換了 UUID 時，只要 URL 相同就仍維持選取。
- 新增專責偏好儲存物件，透過 `UserDefaults` 保存模式與已選 URL；預設值是全部書源。
- `BookSearchView` 觀察 `BookSourceStore.shared`，讓啟用、停用、刪除及匯入後的可用範圍即時更新。
- 已保存的自選 URL 只解析目前仍存在且已啟用的書源。停用或刪除不會默默退回全部書源；若解析後為空，搜尋顯示「請至少選擇一個可用書源」，由使用者修正範圍。
- 編輯並保存自選範圍時，草稿只提交目前可見的已啟用選取，藉此清掉已不存在的陳舊 URL。

## 搜尋資料流

1. 搜尋頁載入持久化範圍。
2. 使用者點擊頂部範圍膠囊，Sheet 以目前範圍建立獨立草稿。
3. 使用者取消時丟棄草稿；完成時驗證並保存範圍。
4. 範圍若改變，搜尋頁呼叫 `SearchAggregator` 的單一「取消並清空」命令，停止舊範圍工作並移除舊結果、進度、分頁及暫停狀態。
5. 使用者提交關鍵字時，搜尋頁把保存範圍解析成已啟用的 `[BookSource]`，再呼叫既有 `search(query:sources:)`。
6. 後續搜尋、暫停、繼續、載入更多、快取、去重、串流發佈與來源健康策略全部維持原路徑。

## 空、載入與錯誤狀態

- 沒有任何已啟用書源：保留現有「尚未設置書源」空狀態。
- 自選模式沒有任何可用書源：不發起搜尋，顯示可操作的錯誤訊息，引導重新選擇搜尋範圍。
- 搜尋中、暫停、無結果及來源逾時／失敗：沿用現有 `SearchAggregator` 狀態與畫面。
- 修改範圍不混用舊結果：保存新範圍時停止並清空舊搜尋，使用者重新提交目前關鍵字後才依新範圍搜尋。
- 不新增自動退回全部、重試、延遲或替代搜尋路徑。

## 無障礙與自適應

- 範圍膠囊及 Sheet 工具列控制的 hit region 至少 44×44pt。
- 裝飾 SF Symbol 對 VoiceOver 隱藏；icon-only 按鈕提供本地化 label。
- 每個可選書源列獨立宣告 label、value／selected trait，不把 accessibility modifier 掛在清單容器。
- 使用語意字體並允許列高隨 Dynamic Type 增長；長書源名稱與 URL 可換行或按資訊優先級截斷。
- 選取狀態不只靠藍色，深色模式及 Increase Contrast 下仍有勾號和文字狀態。
- iPad 由既有 `AdaptiveContentContainer` 與 Sheet 自適應，不加入裝置型號判斷。

## 本地化

所有新增字串經 `localized(...)`，並同步：

- `Resources/zh-Hant.lproj/Localizable.strings`
- `Resources/zh-Hans.lproj/Localizable.strings`
- `Resources/en.lproj/Localizable.strings`

新增文案涵蓋搜尋範圍、全部書源、自選書源、已選數量、選擇書源、清除與至少選擇一個可用書源等狀態。

## 測試與驗收

### 單元／回歸測試

- 未保存偏好時預設解析所有已啟用書源。
- 自選模式只解析選取且已啟用的書源。
- 自選範圍持久化後可完整 round-trip。
- 相同 URL、不同 UUID 的重新匯入書源仍保持選取。
- 已停用或刪除書源不會進入搜尋範圍，也不會自動退回全部。
- `SearchAggregator` 的取消並清空命令會停止搜尋並清除結果、進度、分頁及暫停狀態。

### 驗證命令

- 執行新增的搜尋範圍測試類別。
- 執行直接受影響的聚合搜尋／網路搜尋測試類別。
- 執行 `ruby scripts/check_localizations.rb`。
- 執行 `git diff --check` 與 title-mode 規範 grep。
- 執行最小可靠的 app simulator build，確認 SwiftUI 與目標整合編譯。

### 畫面走查

- 一般使用者：全部書源搜尋、自選多個書源、重新進入 App 後仍保留。
- 受限使用者：VoiceOver、最大 Dynamic Type、單手操作、Reduce Motion、Increase Contrast。
- 邊緣資料：零書源、單一書源、上千書源、超長名稱、重複顯示名稱、書源在保存後被停用／刪除／重新匯入。
- 模擬器檢查 Light、Dark、長本地化字串、鍵盤彈出以及 Sheet 搜尋狀態。
