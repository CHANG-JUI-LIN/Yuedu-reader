# 外觀主題設定分組設計

## 目標

整理 `AppearanceThemeView` 的內容層級，讓相關設定以 iOS Settings 風格分成清楚的 section。這次只調整 section 標題、內容順序與視覺分組，不改變任何設定值、付費判斷、導航或匯入／匯出行為。

## 分組與順序

頁面維持現有 ScrollView、卡片樣式、設計 token 與背景處理，內容改為以下順序：

1. **主題**：主題選擇網格、主題切換、免費使用者的主題自定義升級入口。
2. **閱讀設定**：全局字體、閱讀界面。
3. **介面設定**：界面效果、底部 Tab 自定義（只在目前付費可見時顯示）。
4. **啟動畫面**：啟動圖。
5. **頁面與主題**：頁面背景編輯／預覽，以及 Pro 使用者的主題管理動作；免費使用者保留現有頁面背景升級列。

每個群組使用既有 `sectionHeader` 與 `DSSpacing`。頁面背景區內保留既有的「頁面背景」與「預覽」子標題；主題管理動作增加「主題管理」子標題，讓儲存、匯入、匯出與重置的用途明確。

## 本地化

只新增三個 section 標題，並同步至 `zh-Hant`、`zh-Hans`、`en`：

- `介面設定`
- `啟動畫面`
- `主題管理`

既有的 `主題`、`閱讀設定`、`頁面與主題` 等 key 優先重用。所有標題仍透過 `localized(...)` 取得。

## 行為與驗收

- 點擊每一列的結果與目前完全相同。
- 主題選擇、跟隨系統、閱讀設定、界面效果、啟動圖、底部 Tab、頁面背景與主題管理的狀態流不變。
- Pro／非 Pro 條件顯示不變，只改變它們所屬的 section。
- Light、Dark、Dynamic Type、VoiceOver 與自訂頁面背景仍沿用既有元件和 token。
- 執行 `ruby scripts/check_localizations.rb`、`git diff --check`，並跑直接相關的 `AppearanceThemePresetTests`；App target 編譯成功即可作為本次 UI 重排的回歸驗證。
