# 青空文庫註記普查（2026-10-05）

[文件首頁](../README.md) · [原始數字](annotation-census-2026-10-05.json) · [腳本](../../scripts/aozora_annotation_census.py)

目的：用全庫語料決定青空文庫支援的先後順序，不靠印象。

## 結論

1. **文字正確：現在 57.3% → 查表之後 95.1%。** 「文字正確」指畫面上的每個字都是原作的字。三件事都是查表：外字對照、アクセント分解、くの字点。剩下 4.9% 是只有字形描述、沒有編號的外字。
2. **外字比插圖常見十倍以上：外字 31.0%，插圖 2.8%。** 94.1% 的外字能直接查表：JIS X 0213 編號 87.9%，U+ 碼 6.2%。只有字形描述的佔 5.9%，分佈在 4.9% 的作品裡。
3. **排版保真：現在 28.5% → CSS 可表達的一組 55.1% → 加上傍点／傍線 83.2%。** 傍点出現在 35.9% 的作品，是 CSS 那組以外最大的單項。之後的長尾每一項都加不到 2.5 個百分點。
4. **目錄現在幾乎都不對。** App 的分章規則只在 1.2% 的作品抓到標題，45.2% 被切成每 12 KB 一段。20.5% 的作品有兩個以上的見出し；佔全庫 16.7% 的作品明明有見出し，現在卻是每 12 KB 一段。
5. **檔頭和卷末每本都會碰到。** 記號說明區塊出現在 93.3% 的作品，「底本：」卷末出現在 99.2%。
6. **兩個會讓位置對照出錯的情況。** 15.6% 的作品有「外字後接注音」，現在會露出《…》。3.8% 的作品有 BMP 以外的外字，轉換後 UTF-16 長度從 1 變 2，位置對照必須能處理文字變長。
7. **檔案都不大。** 中位數 10.6 KB、p90 56 KB、p99 395 KB、最大 2.07 MB，整本一次解析沒有問題。17,158 部全部能用 CP932 解碼。

## 語料與方法

- **語料**：[aozorahack/aozorabunko_text](https://github.com/aozorahack/aozorabunko_text) `0984f7dc`。最後一次 commit 是 2023-03-22；README 寫每日同步，實際上已經停更，所以這是 2023 年 3 月的快照。共 17,436 個 TXT，以作品 ID 去重（有 ruby 版就取 ruby 版）後得到 **17,158 部**。
- **語料不進 repo**：部分作品仍受著作權保護，只是經授權放在青空文庫。
- **只統計正文**：每部作品照 aozora2html 的狀態切成檔頭 → 記號說明（兩條 `-----` 之間）→ 正文 → 卷末（從「底本：」開始）。不這樣切的話，每個檔頭的記號說明範例都會被算進去。
- **計數方式**：「作品數」是至少出現一次的作品數，「出現次數」是總次數。分類用關鍵字規則，依序比對，第一條符合的規則決定類別。
- **外字對照**：用 Python 的 `euc_jis_2004`（JIS X 0213:2004）代替 App 將來要用的表，任何正確的 JIS X 0213 → Unicode 表結果都會一樣。抽查結果：1-84-77 → 挘、1-2-24 → ヿ（和 macOS 系統 iconv 的 EUC-JISX0213 結果相同）、2-1-1 → 𠂉（U+20089）、1-4-87 → か゚（組合序列）。
- **目錄**：照 `TXTChapterParser` 的行級 regex（第N章／節／卷／回／篇／部、序章等）和 12 KB 分段規則重現，不包含它在位元組層的前置過濾，所以「抓到標題」的比例只會高估，不會低估。
- **「CSS 可表達」**：指舊 EPUB 樣式模型已有的屬性（`textIndent`、`textAlign`、`marginLeft`、`fontSize`、`fontWeight`、`isItalic`、`pageBreakBefore`）能表達的註記，包括見出し、字下げ、地付き類、改ページ、改行、字級、太字、斜体。直排下的對應還沒逐項驗證。
- **重跑**：`python3 scripts/aozora_annotation_census.py <語料路徑> --json out.json`，4 核心約 6 秒。

## 對分期的意義

- **先做「文字正確」和「結構」**：檔頭／說明區塊／卷末分區（93.3%）、外字查表與外字後的注音（31.0%／15.6%）、くの字点（20.5%）、アクセント分解（2.8%）、用見出し建目錄（20.5%）。這幾項主要是解析器的工作，和選哪個排版引擎無關。
- **再做排版**：CSS 那組加 26.6 個百分點，傍点／傍線再加 28.1 個百分點。傍点兩個引擎都還沒有，要在 YueduCoreText 做 `text-emphasis`。
- **長尾按需求逐項做**：縦中横 3.9%、插圖 2.8%、返り点 2.7%、横組み 2.3%、割り注 1.9%，每一項的累積增益都不到 2.5 個百分點。
- 另外有一項不在這次統計範圍、是讀程式碼確認的：`LocalBookImportService` 把不含音訊的 zip 一律當漫畫匯入，而青空官方下載的是 zip。

## 限制

- 快照停在 2023-03，之後新增的作品沒有算到。
- 分類是關鍵字規則；「其他」佔 238 部（1.4%）。
- 「文字正確」只看外字、アクセント、くの字点，不包含檔頭的記號說明區塊（另外列出）和無 ※ 的外字註記（0.5%）。
- 「排版保真」只看某類註記有沒有出現，不看實作品質。
- 沒有檢查 iOS 字型是否涵蓋轉換後的字；外字對照只抽查了上面列的幾個碼位。
